Unlimited Gunah Simulator — FAQ

Answers about the browser-based Linux-style desktop simulation by kurupdevs (Ayush Jain, Indore, India).

What is Unlimited Gunah Simulator?

Unlimited Gunah Simulator is a Linux-style desktop operating system that runs entirely in a web browser. It recreates the full desktop experience — boot sequence, desktop with wallpapers, dock, start menu, window manager, terminal, settings, apps — using plain HTML, CSS, and JavaScript. Nothing is installed; the whole OS is a website.

Who made Unlimited Gunah Simulator?

Unlimited Gunah Simulator was created by Ayush Jain, an open-source developer from Indore, India, who publishes open-source projects under the GitHub username kurupdevs. His portfolio is at kurupdevs.github.io, and the project's source code is published on his GitHub at github.com/kurupdevs/unlimited-gunah-simulator.

Is Unlimited Gunah Simulator a real Linux distro?

No. Unlimited Gunah Simulator is not a real Linux distribution, kernel, or operating system — it is a browser-based simulation of a Linux-style desktop. It cannot be installed on hardware or run system-level software; it only mimics the look, feel, and interaction of an Ubuntu-style desktop inside a webpage.

How do I run or try Unlimited Gunah Simulator?

Just open kurupdevs.github.io/unlimited-gunah-simulator in any modern browser — no install or download required. Developers can also clone the GitHub repository and open index.html directly, or serve the folder locally with a static server such as npx serve. It works on both desktop and mobile browsers.

Is Unlimited Gunah Simulator free?

Yes. Unlimited Gunah Simulator is completely free to use — there is no price, no subscription, no account, and no paywalled feature. You can run it in your browser, fork it, modify it, and redistribute it under its MIT license, which only asks that you credit kurupdevs.

Is Unlimited Gunah Simulator open source?

Yes. The full source code is published on GitHub at github.com/kurupdevs/unlimited-gunah-simulator under the MIT license. Anyone can read the code, report issues, submit improvements, or fork the project for their own experiments, as long as the original author, kurupdevs, is credited.

What can I do in Unlimited Gunah Simulator?

You get a full simulated desktop: a terminal with neofetch and custom commands plus a portfolio CLI, a file manager, web browser app, paint, notes, calculator, meme viewer, and the KuruBeats music player. You can switch wallpapers, toggle dark mode, use the control center, and hear boot and shutdown sounds and animations.

How is Unlimited Gunah Simulator different from my-os?

Unlimited Gunah Simulator is the new name for the project previously called my-os (also styled as Ubuntu). It is a rebrand of the same browser-based Linux-style desktop simulation by kurupdevs — same features, same author, new name. Older links and pages referencing my-os point to the same project now called Unlimited Gunah Simulator.

Does Unlimited Gunah Simulator work on mobile phones?

Yes. Unlimited Gunah Simulator is responsive and works in mobile browsers as well as on desktop. The interface adapts to smaller screens, so you can open the desktop, apps and terminal from a phone or tablet without installing anything — just visit the GitHub Pages URL.

Where can I download the source code of Unlimited Gunah Simulator?

The source code is hosted on GitHub at github.com/kurupdevs/unlimited-gunah-simulator. You can clone the repository with git, download it as a ZIP from the repository page, or simply open the live version at kurupdevs.github.io/unlimited-gunah-simulator if you only want to try it.
