Unlimited Gunah Simulator

A Linux-style desktop OS that runs entirely in your browser — terminal, apps, wallpapers, dark mode and more. No install, no download.

Try it live Read the FAQ

What is it?

Unlimited Gunah Simulator is a browser-based simulation of a Linux-style desktop. Open the page and you get a full desktop environment in your browser tab: a boot sequence, a top bar, a dock, a start menu, draggable windows, a terminal, and a set of working apps.

To be clear: it is not a real Linux distribution or kernel. It's a front-end experience built with plain HTML, CSS and JavaScript that looks and feels like a Linux desktop. Everything runs locally in your browser — nothing to install, nothing to download, and it works on desktop and mobile.

The project is open source under the MIT license, and the source is on GitHub at github.com/kurupdevs/unlimited-gunah-simulator.

Features

Everything below is real and in the live build:

🖥️

Full desktop environment

Top bar with clock, dock, start menu with app categories, and a working window manager.

⌨️

Terminal with neofetch

A command-line terminal with neofetch, custom commands, and a kurupdevs portfolio CLI (about, projects, skills, github, contact…).

🎨

Wallpapers & dark mode

Multiple built-in wallpapers (Anime, Gaming, Neko, Midori), a dark mode toggle, and a control center.

🧰

Built-in apps

Files manager, notes, calculator, text editor, paint, image viewer, calendar, weather widget and settings.

📄

Office apps

Word, Excel and PowerPoint-style apps, plus a typing tutor — all in the browser.

🎵

KuruBeats & radio

A built-in music player with a live visualizer, plus live internet radio stations.

🌐

Web browser launchers

Quick-launch entries for Chrome, Firefox and Edge, plus messaging and social app icons.

🔊

Boot & shutdown

Animated boot sequence, lock screen, shutdown video and system sounds.

📱

Responsive

Works on desktop and mobile browsers — just open the page.
