# Unlimited Gunah Simulator

**Unlimited Gunah Simulator** is a Linux-style operating system by **[kurupdevs](https://github.com/kurupdevs)** (Ayush Jain) that runs entirely in your browser — no install, no download.

🌐 **Try it live:** https://kurupdevs.github.io/unlimited-gunah-simulator/

## What is it?

Unlimited Gunah Simulator is a full desktop OS experience on the web: a boot sequence, desktop with wallpapers, a dock, start menu, windows, terminal with neofetch, settings, apps, games, and more. It looks and feels like a Linux desktop, built with plain HTML/CSS/JS.

## Features

- 🖥️ Full desktop environment — top bar, dock, start menu, window manager
- ⌨️ Terminal with `neofetch`, custom commands and a portfolio CLI
- 🎨 Multiple wallpapers, dark mode, control center
- 🎮 Built-in games and apps (paint, browser, media player)
- 🔊 Boot/shutdown sounds and animations
- 📱 Responsive — works on desktop and mobile

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
